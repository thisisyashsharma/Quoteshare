# 📝 Quoteshare

**Live Demo:** https://adastrapro.vercel.app/quotes

Quoteshare is a clean, minimal React-based quotes application that lets users browse inspirational quotes through a simple and responsive UI. The project focuses on frontend clarity, smooth user experience, and production-ready deployment.

---

## 🚀 Overview

This project was built to demonstrate:
- Practical React fundamentals
- Clean UI/UX implementation
- Client-side rendering
- Real-world deployment using Vercel

No unnecessary complexity, no overengineering — just a solid, shippable frontend app.

---

## 🧰 TechStack

- **Frontend:** React (Create React App)
- **Styling:** CSS
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

---

## ✨ Features

- Browse curated quotes
- Responsive layout for mobile and desktop
- Fast client-side performance
- Simple, readable codebase
- Zero backend (static deployment)

---

## ⚙️ Local Setup

```bash
git clone https://github.com/thisisyashsharma/Quoteshare.git
cd Quoteshare

npm install
npm start

Open http://localhost:3000 to view it in the browser.

```
---

## 🧠 Implementation Notes

* Built entirely with React components
* Quotes handled via client-side state
* Optimized for static hosting
* Easily extendable with APIs or backend services

---

## 📦 Deployment

The application is deployed on **Vercel**.

🔗 [https://adastrapro.vercel.app/quotes](https://adastrapro.vercel.app/quotes)

Any push to the main branch triggers an automatic redeploy.
